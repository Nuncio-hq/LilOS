# LilOS

Personal CompanyOS on the Hermes harness — a pure web UI over `hermes serve`
JSON-RPC. The goal: run an AI company (teams, roles, work queues) and use it
as an app/marketing factory. Hermes owns all agent state; LilOS owns none.
